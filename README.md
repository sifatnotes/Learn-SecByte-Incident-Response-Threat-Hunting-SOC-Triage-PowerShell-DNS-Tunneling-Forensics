# Learn SecByte Incident Response & Threat Hunting CTF Labs

A curated collection of **hands-on cybersecurity labs and CTF challenges** covering incident response, SOC triage, breach investigation, threat hunting, PowerShell analysis, application auditing, session security, insider threats, and DNS tunneling.

This repository is designed for cybersecurity students, SOC analysts, incident responders, threat hunters, digital forensics learners, and security professionals developing practical defensive skills.

## Introduction

These Learn SecByte labs explore different stages of security operations, from incident classification and validation to intrusion investigation, suspicious activity analysis, and threat hunting.

Use this repository as a searchable learning index for authorized security exercises. Lab descriptions below are based on their supplied names and URLs, not independently verified challenge content.

## How to Use the Labs

1. Open each challenge through its direct Learn SecByte URL.
2. Review its objectives and authorized environment.
3. Practice identifying, validating, classifying, and investigating suspicious activity.
4. Record relevant evidence, event timelines, observations, and conclusions.
5. Explore defensive concepts such as session protection, application auditing, PowerShell monitoring, and DNS anomaly detection.
6. Document lessons learned without exposing real credentials, private data, or sensitive incident information.
